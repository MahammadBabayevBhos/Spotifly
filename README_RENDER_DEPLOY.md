# Render.com-da 7/24 Pulsuz Yerləşdirmə Təlimatı

Bu təlimat vasitəsilə tətbiqinizi **Render.com** platformasında 100% pulsuz yerləşdirə bilərsiniz. Beləliklə, kompüteriniz söndürülsə belə, tətbiq internetdə **7/24 365 gün heç vaxt sönmədən işləyəcək**.

---

## ⚡ Addım-Addım Təlimat (Cəmi 2 Dəqiqə)

### 1. GitHub-a Yükləmək
1. [GitHub.com](https://github.com)-da pulsuz hesab açın.
2. Yeni bir repository (məsələn: `spotifly-downloader`) yaradın.
3. `spotify-downloader-app` qovluğundakı faylları həmin repository-yə push edin.

### 2. Render.com-da Servis Yaratmaq
1. [Render.com](https://render.com) saytına girib pulsuz hesab açın (və ya GitHub ilə giriş edin).
2. Yuxarı sağ küncdən **New +** -> **Web Service** seçin.
3. GitHub hesabınızı bağlayıb `spotifly-downloader` repository-sini seçin.
4. Render tətbiqin daxilindəki `Dockerfile` faylını avtomatik aşkar edəcək!
5. **Language / Runtime**: `Docker` seçildiyindən əmin olun.
6. **Plan**: `Free` ($0/month) seçin və **Create Web Service** düyməsini sıxın.
